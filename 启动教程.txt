==================================
    拼豆商城 - 启动教程
    （每次运行项目参考此文档）
==================================

一、启动前确认
  确保以下软件已安装并正常运行：
  1. JDK 17（验证：命令行输入 java -version）
  2. MySQL 8.0（验证：服务中有 MySQL80 且状态为"正在运行"）
  3. Node.js（验证：命令行输入 node -v）
  4. IntelliJ IDEA

二、启动步骤（每次按顺序操作）

【第1步】确保 MySQL 服务已启动
  - 按 Win+R，输入 services.msc，回车
  - 找到 MySQL80，确认状态为"正在运行"
  - 如果没有运行，右键 → 启动

【第2步】用 IDEA 启动后端
  1. 打开 IntelliJ IDEA
  2. 打开项目：File → Open → 选择桌面上的 pindou-backend 文件夹
  3. 等待 IDEA 加载完成（右下角进度条跑完）
  4. 找到 src/main/java/com/pindou/PindouApplication.java
  5. 右键 → Run 'PindouApplication'
  6. 看到控制台显示 "Tomcat started on port 8080" 就说明后端启动成功

【第3步】启动前端（出现cd报错可以询问ai进行命令解决）
  1. 按 Win+R，输入 cmd，回车打开命令提示符
  2. 输入以下命令（按回车执行）：

     cd 桌面\pindou-frontend
     npm run dev

  3. 看到类似 "Local: http://localhost:5173/" 的提示就说明前端启动成功
  4. 注意：这个命令行窗口不要关闭！关闭就会停止前端

【第4步】访问系统
  打开浏览器（推荐Chrome），访问：
  http://localhost:5173

三、测试账号

  管理员：admin / 123456
    （可以管理商品、分类、订单、用户、轮播图）

  普通用户：user1 / 123456
    （可以浏览商品、加购物车、下单、评价）

  普通用户：user2 / 123456

  后台管理入口：http://localhost:5173/admin

四、关闭项目

  1. 关闭前端：在命令行窗口按 Ctrl+C
  2. 关闭后端：在 IDEA 中点击红色方块停止按钮
  3. MySQL 服务不用关，它会在后台自动运行

五、常见问题

  问题1：后端启动报错"数据库连接失败"
  解决：检查 MySQL 服务是否启动（步骤1）

  问题2：前端页面空白
  解决：确保后端已经启动成功（步骤2），然后刷新页面

  问题3：npm run dev 报错
  解决：先执行 npm install，然后再 npm run dev

  问题4：图片不显示
  解决：需要联网，图片使用的是在线图片链接

六、数据库信息（仅供参考，一般不需要修改）

  用户名：root
  密码：root
  端口：3306
