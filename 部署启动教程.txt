================================================================================
              拼豆商城 —— 完整部署启动教程
              使用 IntelliJ IDEA 部署 Spring Boot + Vue3
================================================================================

本教程从零开始，手把手教你如何在本地电脑上运行整个拼豆商城项目。
即使你是完全的新手，按照步骤一步步来也能成功运行。

================================================================================
第一部分：需要安装的软件（共 4 个）
================================================================================

【软件1】JDK 17（Java 开发环境）
────────────────────────────────
  下载地址：https://www.oracle.com/java/technologies/javase/jdk17-archive-downloads.html
  备选地址：https://adoptium.net/temurin/releases/?version=17
  
  安装步骤：
    1. 打开上面的链接，选择 Windows x64 Installer（.msi 或 .exe 格式）
    2. 下载完成后双击运行安装程序
    3. 一路点击 "Next"（下一步），使用默认安装路径即可
    4. 安装完成后，验证是否成功：
       - 按 Win+R，输入 cmd，回车打开命令行
       - 输入：java -version
       - 如果显示 "java version 17.x.x" 就说明安装成功

  配置环境变量（如果 java -version 没反应）：
    1. 右键「此电脑」→ 属性 → 高级系统设置 → 环境变量
    2. 在「系统变量」中新建：
       变量名：JAVA_HOME
       变量值：C:\Program Files\Java\jdk-17（你的JDK安装路径）
    3. 找到 Path 变量，编辑，新增一行：%JAVA_HOME%\bin
    4. 点确定保存，重新打开命令行测试


【软件2】MySQL 8.0（数据库）
────────────────────────────────
  下载地址：https://dev.mysql.com/downloads/mysql/
  备选地址：https://dev.mysql.com/downloads/installer/
  
  安装步骤：
    1. 打开链接，选择 "MySQL Installer for Windows"
    2. 下载 mysql-installer-community-8.0.xx.msi
    3. 双击运行，选择 "Developer Default" 或 "Server only"
    4. 安装过程中会让你设置 root 密码，请记住你设置的密码！
       （建议设为简单的如：123456 或 root）
    5. 其他选项保持默认，一直点 Next 直到完成
    6. 验证：打开命令行输入 mysql -u root -p，输入密码后能进入就OK

  重要提示：记住你设置的 MySQL root 密码，后面要用到！


【软件3】Node.js（前端运行环境）
────────────────────────────────
  下载地址：https://nodejs.org/en/download/
  推荐版本：LTS 长期支持版（如 18.x 或 20.x 都可以）
  
  安装步骤：
    1. 打开链接，点击 Windows Installer (.msi)，选 64-bit
    2. 下载后双击运行，一直点 Next，使用默认路径
    3. 验证：打开命令行
       - 输入：node -v    （应该显示 v18.xx.x 或更高）
       - 输入：npm -v     （应该显示 9.x.x 或更高）


【软件4】IntelliJ IDEA（开发工具）
────────────────────────────────
  下载地址：https://www.jetbrains.com/idea/download/
  
  选择版本：
    - Community（社区版）—— 免费，够用
    - Ultimate（旗舰版）—— 付费，功能更多（有30天试用）
  
  安装步骤：
    1. 下载 .exe 安装包
    2. 双击运行，一直点 Next
    3. 安装选项中勾选：
       ✅ 64-bit launcher（桌面快捷方式）
       ✅ Add "Open Folder as Project"
       ✅ .java 文件关联
    4. 安装完成后启动 IDEA


================================================================================
第二部分：导入数据库
================================================================================

  1. 打开命令行（Win+R → 输入 cmd → 回车）

  2. 登录 MySQL：
     mysql -u root -p
     （输入你安装MySQL时设置的密码）

  3. 复制粘贴以下内容执行（或者用 source 命令导入SQL文件）：
     source 你的项目路径/pindou-backend/src/main/resources/pindou_mall.sql
     
     例如：
     source D:/projects/拼豆商城/pindou-backend/src/main/resources/pindou_mall.sql

  4. 验证数据库是否创建成功：
     USE pindou_mall;
     SHOW TABLES;
     （应该看到 users, products, categories 等 9 张表）
     
     SELECT COUNT(*) FROM products;
     （应该显示 15，表示有 15 个商品数据）

  5. 输入 exit 退出 MySQL


================================================================================
第三部分：用 IDEA 启动后端（Spring Boot）
================================================================================

  1. 打开 IntelliJ IDEA

  2. 点击 "Open"（打开项目）
     → 选择项目中的 pindou-backend 文件夹
     → 点击 OK

  3. 等待 IDEA 加载项目（右下角会显示进度条，首次加载需要下载依赖，
     可能需要 5-15 分钟，请耐心等待）

  4. ★★★ 修改数据库密码配置 ★★★
     这一步非常重要！！
     
     在 IDEA 左侧项目树中找到并打开：
     src → main → resources → application.yml
     
     找到这两行：
       username: root
       password: root
     
     将 password 后面的值改为你安装MySQL时设置的密码！
     例如你的密码是 123456，就改成：
       password: 123456
     
     按 Ctrl+S 保存

  5. 运行后端：
     方法一：在 IDEA 左侧找到 src/main/java/com/pindou/PindouApplication.java
             右键 → Run 'PindouApplication'
     
     方法二：点击 IDEA 右上角的绿色三角形 ▶ 运行按钮

  6. 等待启动完成，控制台出现以下信息表示成功：
     "Started PindouApplication in x.xx seconds"
     "Tomcat started on port(s): 8080"

  7. 验证：打开浏览器访问 http://localhost:8080/api/category/list
     如果看到 JSON 数据，说明后端启动成功！

  常见错误处理：
    ❌ "Port 8080 is already in use"
       → 说明 8080 端口被占用
       → 打开命令行输入：netstat -ano | findstr :8080
       → 找到 PID，然后：taskkill /PID xxx /F
       → 重新运行

    ❌ "Access denied for user 'root'@'localhost'"
       → 数据库密码不对，检查 application.yml 中的 password

    ❌ "Communications link failure"
       → MySQL 服务没启动
       → 打开 Windows 服务（services.msc），找到 MySQL，点启动

第四部分：启动前端（Vue3）
================================================================================

  1. 打开命令行（Win+R → cmd）

  2. 进入前端项目目录：
     cd 你的项目路径\pindou-frontend
     
     例如：
     cd D:\projects\拼豆商城\pindou-frontend

  3. 安装前端依赖（首次运行需要，以后不用）：
     npm install --legacy-peer-deps
     
     等待安装完成（可能需要 2-5 分钟）

  4. 启动前端开发服务器：
     npm run dev

  5. 启动成功后会显示：
     VITE v8.x.x  ready in xxx ms
     ➜  Local:   http://localhost:5173/
  
  6. 打开浏览器访问显示的地址（通常是 http://localhost:5173）

  注意：启动前端之前，确保后端已经在运行！

第五部分：访问和使用
================================================================================

  前台首页：http://localhost:5173
  后台管理：http://localhost:5173/admin（需要管理员账号登录）

  测试账号：
  ┌──────────┬──────────┬──────────┐
  │   角色   │  用户名  │   密码   │
  ├──────────┼──────────┼──────────┤
  │ 管理员   │  admin   │  123456  │
  │ 普通用户 │  user1   │  123456  │
  │ 普通用户 │  user2   │  123456  │
  └──────────┴──────────┴──────────┘

  管理员功能：
    - 商品管理（添加/编辑/删除/上下架商品，支持图片上传）
    - 分类管理（添加/编辑/删除商品分类）
    - 订单管理（查看订单/发货）
    - 用户管理（查看用户/禁用启用）
    - 轮播图管理（添加/编辑/删除首页轮播图）

  普通用户功能：
    - 浏览商品、搜索商品
    - 查看商品详情、评价
    - 加入购物车、修改数量
    - 提交订单、支付、取消、确认收货
    - 商品评价
    - 个人信息修改、密码修改
    - 收货地址管理


================================================================================
第六部分：常见问题 FAQ
================================================================================

  Q1: npm install 报错怎么办？
  A1: 尝试使用：npm install --legacy-peer-deps --force
      或者删除 node_modules 文件夹后重试

  Q2: 前端页面打开是空白怎么办？
  A2: 按 F12 打开浏览器开发者工具，查看 Console 是否有报错
      通常是后端没有启动导致的

  Q3: 如何停止运行？
  A3: 后端：在 IDEA 中点击红色方块 ■ 停止按钮
      前端：在命令行窗口按 Ctrl+C

  Q4: 如何修改端口？
  A4: 后端端口在 application.yml 的 server.port 修改
      前端端口在 vite.config.js 的 server.port 修改

  Q5: 图片上传后在哪里？
  A5: 上传的图片保存在 pindou-backend/upload/ 目录下
