一、项目概述
================================================================================

  项目名称：拼豆商城
  项目描述：一个二次元拼豆手工艺品电商平台
  
  技术架构：前后端分离
    - 后端：Spring Boot 2.7.18 + MyBatis-Plus 3.5.5 + MySQL 8.0
    - 前端：Vue 3 + Vite + Element Plus + Vue Router 4 + Pinia
    - 认证：JWT (JSON Web Token)
    - 密码加密：MD5 (Hutool)

三、数据库设计（共 9 张表）
================================================================================

  1. users（用户表）
     - id: 主键自增
     - username: 用户名（唯一）
     - password: 密码（MD5加密存储）
     - nickname: 昵称
     - avatar: 头像URL
     - phone: 手机号
     - email: 邮箱
     - role: 角色（USER普通用户 / ADMIN管理员）
     - status: 状态（1启用 / 0禁用）
     - create_time, update_time: 创建/更新时间

  2. categories（商品分类表）
     - id, name(分类名), icon(图标), sort_order(排序), status

  3. products（商品表）
     - id, name(商品名), category_id(分类ID), price(售价),
       original_price(原价), stock(库存), sales(销量),
       main_image(主图), images(多图), description(简介),
       detail(富文本详情), ip_series(IP系列), character_name(角色),
       status(1上架/0下架), is_hot(热门), is_new(新品), view_count(浏览量)

  4. carts（购物车表）
     - id, user_id, product_id, quantity(数量), checked(是否选中)

  5. orders（订单表）
     - id, order_no(订单号), user_id, total_amount(总金额),
       status(0待付款/1已付款/2已发货/3已完成/4已取消),
       address(收货地址), phone, receiver(收货人), remark(备注)

  6. order_items（订单详情表）
     - id, order_id, product_id, product_name, product_image, price, quantity

  7. reviews（评价表）
     - id, user_id, product_id, order_id, content(评价内容),
       rating(评分1-5), images(评价图片)

  8. banners（轮播图表）
     - id, title(标题), image(图片), url(链接), sort_order, status

  9. addresses（收货地址表）
     - id, user_id, receiver, phone, province, city, district, detail, is_default

六、核心业务流程
================================================================================

  【下单流程】
  用户浏览商品 → 加入购物车 → 勾选商品 → 去结算
  → 填写收货信息 → 提交订单 → 系统创建订单
  → 自动扣减库存、增加销量、清除购物车已选商品
  → 用户支付 → 管理员发货 → 用户确认收货 → 可以评价

  【认证流程】
  用户登录 → 后端验证账密 → 生成JWT Token → 返回给前端
  → 前端存储Token到localStorage → 后续请求在Header中携带Token
  → 后端拦截器验证Token → 从Token中获取用户ID和角色

  【数据流】
  前端按钮点击 → 调用API函数(api/index.js) → Axios发HTTP请求
  → 后端Controller接收 → 调用Mapper操作数据库 → 返回Result
  → Axios拦截器处理响应 → 前端更新页面数据


七、关键配置文件说明
================================================================================

  【后端 application.yml】
  - server.port: 后端端口（默认8080）
  - spring.datasource: 数据库连接信息（URL、用户名、密码）
  - mybatis-plus: MyBatis-Plus配置（Mapper路径、驼峰映射等）
  - jwt.secret: JWT加密密钥
  - jwt.expiration: Token过期时间（毫秒，默认24小时）
  - file.upload-path: 文件上传存储路径

  【前端 vite.config.js】
  - server.port: 前端端口（默认5173）
  - server.proxy: 代理配置（将/api请求转发到后端8080）
